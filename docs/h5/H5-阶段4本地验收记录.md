## 本地执行方法

浏览器脚本要求本地前端和后端已启动，且使用专用测试账号：

```powershell
$env:PLAYWRIGHT_MODULE='<workspace dependency>/node_modules/playwright'
$env:H5_BROWSER_PATH='<Edge or Chrome executable>'
$env:H5_BASE_URL='http://127.0.0.1:5173'
$env:H5_E2E_USER='<test user>'
$env:H5_E2E_PASSWORD='<test password>'
node scripts/verify-h5-browser.cjs
node scripts/verify-h5-session-load.cjs
```

不得使用真实患者数据或生产账号执行本地浏览器测试。
