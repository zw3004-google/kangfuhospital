# H1：移动基础与安全本地实施记录

> 完成日期：2026-09-05
> 实施范围：仅本地开发和验证，未部署测试环境。

## 已实现

- 应用壳层支持手机、平板和桌面断点；手机端隐藏固定侧栏，改用左侧抽屉导航。
- 去除手机端 1180px 最小宽度限制，补充安全区、触控尺寸、移动卡片、筛选和弹窗等通用样式。
- 增加当前登录人和日期的低干扰动态水印。
- 页面进入后台时遮盖业务内容，返回前台恢复。
- 空闲 30 分钟后退出，并在重新登录后支持返回原业务路径。
- 前端移除 `sessionStorage` 中的 Basic 凭据，不再保存账号密码编码。
- 后端提供 `/api/auth/login` 会话登录和 `/api/auth/logout` 会话注销，浏览器使用同源 Cookie。
- 后端暂时保留 HTTP Basic，仅用于兼容既有接口自动化和非浏览器调用；Web 前端已不再使用。
- HTTP 客户端增加断网、401、403、404 和超时的差异化错误处理。
- 登录页适配服务端会话登录，并保留原有账号锁定和首次改密流程。

## 安全说明

- 当前后端沿用原系统 `csrf.disable()`。H1 已消除浏览器长期持有 Basic 凭据的主要风险，但启用生产 HTTPS Cookie 前仍需完成 CSRF 策略评审。
- 正式部署时应将会话 Cookie 配置为 `HttpOnly`、`Secure` 和适当的 `SameSite`，并确认内网 HTTPS 证书受手机信任。
- H1 未实现企微免登录，符合一期范围。
