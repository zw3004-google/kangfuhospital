实施日期：2026-09-05
实施范围：仅本地开发与验证，未部署测试环境。

## 已完成

- 预计出院页面保留主管医生、门诊部、营养科、居家康复科、随访员五个责任分区，并在手机端使用单列表单、全屏编辑和触控友好输入。
- 欠费及预计出院编辑加入会话内草稿；保存成功、主动退出或会话超时后清理，保存失败时保留以便继续提交。
- 欠费及预计出院记录响应增加 `updatedAt` 版本令牌；更新请求携带 `expectedUpdatedAt`，服务端在同一条 SQL 中原子比对。版本冲突返回 HTTP 409，阻止后写覆盖先写。
- 保存按钮继续使用 `loading/disabled` 防止重复点击；快捷缴费也提交版本令牌。
- 统计分析保留指标与触控趋势图，六类业务明细增加移动卡片下钻视图，手机默认每页 20 条。
- 欠费/预出院推送记录增加移动卡片和全屏尝试详情；移动端仅提供查询与尝试详情，不显示单条或批量重发。
- 409、离线、超时及权限错误均由统一 HTTP 层转换为明确中文提示。
