# 阶段 3：业务功能回归

> 执行日期：2026-08-31  
> 状态：`VERIFIED`——导入、欠费、预出院、预约、推送和审计核心流程已形成 PostgreSQL 集成测试闭环。  
> 后续状态：阶段 4 前端完整联调已完成并通过验收，参见 [`../phase4/README.md`](../phase4/README.md)。

## 1. 已完成

- 欠费与预出院真实 Excel 映射、固定列顺序和空文件校验。
- 全量行校验、文件内重复键拒绝、科室和费别引用校验，任一错误整批不写业务数据。
- 同类导入使用 PostgreSQL 事务锁串行执行。
- 重复导入覆盖源字段、重新固化金额，同时保留缴费状态、欠费原因和追缴进度。
- 空白源字段不清除已有值；空白预计出院时间不覆盖人工值。
- 成功批次记录新增、覆盖、跳过和医生匹配统计；报表返回最新成功批次与数据截至时间。
- 失败批次与逐行错误独立持久化，支持按批次查看错误详情。
- 欠费、预出院、会诊预约、导入、导出及人工重发记录审计前后值、操作人和客户端 IP。
- 预约时间禁止设置为过去，删除使用逻辑删除并保留审计。
- 推送采用 `PENDING → SENDING → RETRYING/SENT/FAILED` 状态流转，失败后按 1、5、15 分钟重试。
- 自动与人工发送尝试连续编号，保存触发方式、计划/实际时间、接收人快照、错误码和脱敏错误。
- 单条及批量人工重发沿用原主任务并保留历史尝试。
- CSV 导出增加引号、换行和公式注入安全转义。
- 审计接口统一为 `/api/system/audit-logs`；不存在资源返回 404。
