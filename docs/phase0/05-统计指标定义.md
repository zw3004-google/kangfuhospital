# 统计指标定义

## 1. 通用统计口径

- 患者去重键：住院号 + 住院次数。
- 月份归属：按实际出院时间所在自然月。
- 时间边界：上海时区 `[月初 00:00, 次月月初 00:00)`。
- 实际出院时间为空的在院患者不进入出院指标分母。
- 实际出院时间被清空时，从原出院月份统计中移除并重算。
- 分母为 0 时显示“—”，趋势点为空，不显示为 0%。
- 百分比建议保留 2 位小数并四舍五入。
- 月趋势为当月 1 日至该日的累计指标，不是单日指标。
- 统计默认应用当前用户 `DataScope`；系统管理员和运营部查看全院统计（已确认）。

## 2. 预出院核心指标

### 2.1 实际出院人数

```text
分子：统计月内实际出院的一次住院记录数
去重：住院号 + 住院次数
```

### 2.2 非计划出院率

```text
分子：统计月实际出院患者中，预计出院日期为空
      或预计出院日期 != 实际出院日期的患者数
分母：统计月实际出院患者数
月份：实际出院月份
```

- 多次修改预计出院时间时使用最后一次值。
- 跨月预计、实际出院时按实际出院月份统计。
- `LATE_PLAN` 本身不改变非计划出院率，除非同时缺失或日期不一致。

### 2.3 营养会诊预约率

```text
分子：统计月实际出院患者中，存在至少一条未删除营养会诊预约的患者数
分母：统计月实际出院患者数
去重：一次住院只计 1 人
月份：实际出院月份，不按预约月份
```

### 2.4 居家康复预约率

```text
分子：统计月实际出院患者中，存在至少一条未删除居家康复预约的患者数
分母：统计月实际出院患者数
去重：一次住院只计 1 人
月份：实际出院月份
```

### 2.5 复诊预约率

```text
分子：统计月实际出院患者中，存在至少一次复诊预约的患者数
分母：统计月实际出院患者数
去重：一次住院只计 1 人
月份：实际出院月份
```

当前数据库只有单个 `outpatient_appointment_at` 字段，需求表述为“至少一次”；是否需要一对多复诊预约表是待确认/待设计项。

## 3. 欠费指标

### 3.1 当前欠费人数

```text
COUNT(一次住院)
WHERE 押金差额 < 0 AND 缴费状态 != PAID
```

### 3.2 当前欠费合计

```text
SUM(欠费金额)
WHERE 押金差额 < 0 AND 缴费状态 != PAID
```

### 3.3 科室排名和 Top3

- 按患者当前所属科室分组。
- 汇总当前欠费金额，金额降序。
- Top3 为全院前三个科室；并列时建议以科室编码升序稳定排序。
- 报表截至最新成功导入/API 获取批次。
- 最新批次失败或汇总未完成时继续展示上一成功批次。

## 4. 看板与明细一致性

- 六个预出院看板都来自预计出院管理列表的同一数据源。
- 看板数值应可点击或通过同条件明细核对。
- 时间筛选、科室筛选和 `DataScope` 必须同时作用于看板、趋势、列表和导出。
- 导出应包含所选时间区间内的全部列表字段，并受相同数据权限控制。

## 5. 指标验收样例

某月有 4 次实际出院：A 计划与实际同日；B 不同日；C 未填计划；D 同日且有两次营养预约。则：

- 实际出院人数 = 4。
- 非计划出院人数 = 2，非计划出院率 = 50.00%。
- 若仅 D 有营养预约，营养预约人数 = 1、预约率 = 25.00%，不能因两次预约计为 2 人。
- 删除 D 全部营养预约后，营养人数立即变为 0、预约率为 0.00%。

在没有实际出院患者的月份，所有率显示“—”。
