# 导入模板与覆盖矩阵

## 1. 导入基线

- 第一期使用固定 `.xlsx` 模板；后续预留 API 数据源。
- 单批不超过 1000 条；同一业务同一时刻只允许一个批次处理。
- 欠费由财务科和运营部导入的最终授权待确认；预出院由运营部和系统管理员导入。
- 一次住院以“住院号 + 住院次数”定位。
- 同一文件内出现重复唯一键：整批失败并报告重复行，禁止静默采用最后一行。
- 采用“全量校验 + 单批事务”：任一行失败则整批回滚，禁止产生半批数据（已确认）。

## 2. 推荐模板字段

### 2.1 公共住院字段

| 表头 | 必填 | 格式/校验 |
|---|:---:|---|
| 住院号 | 是 | 文本，保留前导零，最长 64 |
| 住院次数 | 是 | 正整数 |
| 姓名 | 是 | 文本，最长 128 |
| 科室编码 | 是* | 正式编码待信息科提供；不建议仅用科室名称 |
| 科室名称 | 是 | 展示和人工核对 |
| 住院病区 | 否 | 文本 |
| 费别 | 是 | 仅填写费别名称，必须能匹配系统中同名且已启用的费别系数；不要求填写费别编码 |
| 主管医生工号 | 是* | 工号精确匹配唯一启用用户；*正式模板建议必填 |
| 主管医生姓名 | 否 | 仅展示和核对，不参与关联 |
| 入区时间 | 是* | 推荐 `yyyy-MM-dd HH:mm` |
| 实际出院时间 | 否 | 推荐 `yyyy-MM-dd HH:mm` |

### 2.2 欠费字段

| 表头 | 必填 | 校验 |
|---|:---:|---|
| 欠费类型 | 否* | 正式枚举待业务确认 |
| 总费用（元） | 否 | 非负，两位小数 |
| 预交金（元） | 是 | 非负，两位小数 |
| 医保支付（元） | 否 | 非负，两位小数，空值按 0 的规则待确认 |
| 个人账户支付（元） | 否 | 非负，两位小数，空值按 0 的规则待确认 |
| 原始应交押金（元） | 是 | 非负，两位小数 |

最终应交押金、押金差额、是否欠费和欠费金额由系统计算，不接受模板直接覆盖。

### 2.3 预出院字段

| 表头 | 必填 | 校验 |
|---|:---:|---|
| 预计出院时间 | 否 | 推荐 `yyyy-MM-dd HH:mm`；是否允许源文件覆盖人工填报值待确认 |
| 实际出院时间 | 否 | 推荐 `yyyy-MM-dd HH:mm` |

业务填报字段、会诊预约、随访内容不放入常规源数据导入模板。

## 3. 重复导入覆盖矩阵

| 字段组 | 示例 | 处理 |
|---|---|---|
| 唯一键 | 住院号、住院次数 | 仅用于定位，不通过更新改变 |
| 患者源字段 | 姓名、病区、费别、主管医生、入区/出区时间 | 最新成功批次覆盖 |
| 科室 | 当前科室 | 转科后覆盖原记录并更新数据范围 |
| 欠费源字段 | 类型、费用、预交金、医保支付、个人账户支付、原始押金 | 覆盖 |
| 欠费计算字段 | 系数快照、最终押金、差额、是否欠费、欠费金额 | 按本批次重算 |
| 欠费人工字段 | 缴费状态、欠费原因、追缴进度 | 保留 |
| 预出院源字段 | 实际出院时间 | 覆盖并触发状态、异常、提醒和统计重算 |
| 预计出院时间 | 人工填报/源数据 | 空白导入值不覆盖人工值；非空导入值直接覆盖（已确认） |
| 预出院人工字段 | 异常原因、特殊患者、预约、随访 | 保留 |
| 系统字段 | 创建人、创建时间、审计记录 | 系统维护，不覆盖 |

空白源字段表示未提供，不清除已有值；若业务需要清空，必须使用明确的“清空标记”、专用操作或 API 语义（已确认）。

## 4. 校验顺序

1. 文件扩展名、内容类型、大小、模板版本和表头。
2. 必填、长度、数字、金额和日期格式。
3. 唯一键及文件内重复键。
4. 科室、费别系数等主数据引用。
5. 主管医生按工号匹配启用用户（未匹配不阻断业务导入，但记录原因且不发送医生提醒）。
6. 业务规则和跨字段关系。
7. 开启事务、写入、重算、提交。
8. 提交后异步刷新汇总；汇总完成后切换报表批次。

## 5. 导入结果与错误报告

成功结果至少返回：批次号、总数、新增数、覆盖数、跳过数、失败数、医生匹配数、工号未匹配数、工号冲突数、开始/结束时间。

错误报告至少包含：Excel 行号、住院号、住院次数、字段名、原始值、错误编码、中文说明。错误示例：

| 错误编码 | 含义 |
|---|---|
| `INVALID_TEMPLATE` | 模板版本或表头错误 |
| `MISSING_REQUIRED` | 必填字段缺失 |
| `INVALID_FORMAT` | 金额、日期或整数格式错误 |
| `DUPLICATE_KEY_IN_FILE` | 文件内唯一键重复 |
| `DEPARTMENT_NOT_FOUND` | 科室无法匹配 |
| `FEE_COEFFICIENT_NOT_FOUND` | 无当前启用费别系数 |
| `BATCH_IN_PROGRESS` | 同业务已有批次执行中 |

原始文件建议至少保留 1 年，最终保留期限由医院确认；文件访问必须受权限控制并记录审计。
