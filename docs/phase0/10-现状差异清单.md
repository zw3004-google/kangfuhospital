## 处理原则

1. 阶段 2 已关闭权限与数据范围相关 P0 差异；剩余 P0 项在阶段 3 核心业务回归中解决。
2. P1 差异在对应模块端到端联调前解决。
3. P2 差异不阻塞业务开发，但阻塞生产验收。
4. 每项关闭时附代码提交、自动化测试或验收记录链接，不能只修改状态文字。
