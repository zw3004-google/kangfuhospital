## 3. 已确认的关键结论

1. 一次住院唯一键为“住院号 + 住院次数”，欠费和预出院共用患者及住院信息。
2. 第一期由 Excel 导入，后续预留接口获取；不删除欠费或预出院主业务记录。
3. 患者转科、姓名变化和源数据变化均覆盖同一次住院记录；人工业务字段保留。
4. 主管医生按工号精确匹配唯一启用用户，并保留原始工号、原始姓名和匹配状态。
5. 押金差额允许正、零、负；仅差额小于 0 且未标记已缴费的记录进入欠费统计和推送。
6. 第一期所有登录用户均可编辑其数据范围内可见患者，保留导入、导出、推送和系统管理权限控制。
7. 统计月份按实际出院时间归属，患者按一次住院唯一键去重；分母为 0 时显示“—”。
8. 所有时间使用 `Asia/Shanghai`，生产环境必须同步医院 NTP。
