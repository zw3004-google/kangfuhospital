# 费别系数配置编码与版本化实施记录

## 已确认口径

- 费别编码由系统管理员输入，仅支持字母和数字，保存时统一为大写。
- 费别编码用于系统内唯一识别；欠费导入模板不增加编码，仍仅按费别名称匹配。
- 同一费别允许存在多个系数版本，同一时间只允许启用一个版本。
- 新增版本继承费别编码和名称；历史欠费固化系数、计算结果及系数版本 ID，不追溯重算。
- 最终应交押金 = 原始应交押金 × 当前启用的费别系数。

## 实施内容

- Flyway V23 新增费别主数据、编码唯一约束、版本操作人字段及欠费系数版本快照。
- 费别配置接口支持编码、名称和状态筛选，并按费别主数据管理历史版本。
- 欠费导入继续按规范化后的费别名称匹配启用版本，模板字段不变。
- 页面增加计算口径、费别编码、计算示例、状态筛选、最近操作人和新增版本入口。
- 新增费别时校验 1～32 位字母数字编码；新增版本时编码和名称只读。

## 存量数据

V23 为升级前已有费别生成 `LEGACYnnn` 迁移编码，以保证迁移可重复且历史记录不丢失。上线前应由业务管理员核对存量编码；新建费别必须由用户输入正式编码。
