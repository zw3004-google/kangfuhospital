# 发布说明

## v1.0.0 — 2026-09-05

首个正式编号版本，建立当前测试环境的发布基线。对比基准：此前未编号测试版本；Git 基准为 `248336b1ce8e29c51d1ed68d6b0177f090d48a8d`。版本标签按本次用户指定采用小写 `v1.0.0`，前后端包版本为 `1.0.0`。

### 初始功能范围

- 欠费管理：欠费明细、推送记录、通报报表及相关权限控制。
- 预出院管理：患者工作台、会诊、随访、出院提醒和分析。
- 系统管理：用户、角色、字段权限、审计及费用系数配置。
- 企业微信消息集成与计划任务；实际凭据通过环境变量配置。
- H5 响应式导航和核心业务页面适配，移动端表单与会话草稿保护。

### 问题修复与安全改进

- Session 登录与 CSRF Token 校验，可信来源校验及失效会话处理；权限、账号状态和密码变更及时影响已有会话。
- 欠费和预出院更新增加并发冲突提示，避免无提示覆盖。
- 权限管理交互与前后端验证完善，页面安全响应头和相关回归测试补齐。
- 修复测试环境 HTTPS 由 Nginx 转 HTTP 后，缺少可信来源配置导致登录报“请求来源不受信任”的部署问题。

### 配置与数据库

- 腾讯云环境必须设置 `APP_ALLOWED_ORIGINS=https://kangfu.pkucarewiki.cn`；修改后重启 `kangfu-test`。
- HTTPS 环境应配置 `SESSION_COOKIE_SECURE=true`；离线 HTTP 环境按实际协议配置。不得关闭来源校验或 CSRF 防护。
- 数据库基线为 Flyway V1～V23；本次版本流程补齐不新增迁移。升级已有测试环境不重建或清空数据。
- 环境文件、密钥、患者数据及构建缓存不提交 Git。
