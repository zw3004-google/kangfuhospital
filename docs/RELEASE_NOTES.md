# 发布说明

## V1.1.2 — 2026-09-06

对比基准：V1.1.1。

### 新增功能

- 系统管理的科室管理支持按科室编码、科室名称和状态组合检索，并提供服务端分页（20、50、100、200 条）。

### 问题修复

- 欠费明细导入遇到同名且启用的科室时不再因查询结果多条而整体回滚；系统按最早创建的匹配科室稳定归属记录。

### 配置与数据库

- 不新增数据库迁移，不修改测试环境运行配置；发布保留既有业务数据。

### 已知问题

- 历史同名科室数据仍需后续治理；在未完成合并前，欠费导入会选用最早创建的启用科室。

## V1.1.1 — 2026-09-05

对比基准：V1.1.0。

### 新增功能

- 用户管理和科室管理支持单个删除、批量删除、批量启用及批量停用。
- 顶部导航调整为帮助入口、版本标识和用户下拉菜单；科室管理恢复模板导出、数据导出及导入入口。

### 问题修复

- 用户登录名改为企微 ID；默认密码和重置密码统一为 `kfyy123!`。
- 用户与科室导入成功后显示文件名、总数、成功数和失败数；导入后的列表刷新失败不再误报为导入失败。
- 欠费导入兼容多工作表、源表别名和公式金额；预出院导入兼容源表字段、医生工号、超过 1,000 条的数据及重复科室名称。

### 配置与数据库

- 不新增数据库迁移。测试环境部署前保留现有数据和环境配置。

### 已知问题

- 预出院源表的医生工号需与系统用户工号一致；不一致的记录可以导入，但医生关联状态为未匹配。

## V1.1.0 — 2026-09-05

对比基准：v1.0.0。新增移动端统一工作台入口、浏览器密码管理器记住密码、用户与科室 Excel 模板导出/数据导出/数据导入、右上角版本及用户手册入口、修改密码快捷入口。

### 新增功能

- 手机端和 Web 端登录成功后均默认进入工作台。
- 记住密码仅使用浏览器或设备的凭据管理器保存，不在系统本地存储明文密码。
- 用户管理支持模板导出、用户导出和 xlsx 导入；科室管理支持同类操作。
- 右上角显示 V1.1.0，并提供用户手册下载和修改密码入口。
- 新增覆盖全系统的版本化 Word 用户手册，包含登录、业务模块、系统管理、移动端、常见问题和修改记录。

### 配置与数据库

- 不涉及数据库结构或运行配置变更。
- 测试环境部署记录在部署完成后追加至 docs/DEPLOYMENT_HISTORY.md。

### 已知问题

- 用户手册已生成；当前本机缺少捆绑 LibreOffice 渲染器，无法完成自动页面渲染复核，发布前需在具备渲染器的构建机复核版式。

## v1.0.0 — 2026-09-05

首个正式编号版本，建立当前测试环境的发布基线。对比基准：此前未编号测试版本；Git 基准为 `248336b1ce8e29c51d1ed68d6b0177f090d48a8d`。版本标签按本次用户指定采用小写 `v1.0.0`，前后端包版本为 `1.0.0`。

### 初始功能范围

- 欠费管理：欠费明细、推送记录、通报报表及相关权限控制。
- 预出院管理：患者工作台、会诊、随访、出院提醒和分析。
- 系统管理：用户、角色、字段权限、审计及费用系数配置。
- 企业微信消息集成与计划任务；实际凭据通过环境变量配置。
- H5 响应式导航和核心业务页面适配，移动端表单与会话草稿保护。

### 问题修复与安全改进

- Session 登录与 CSRF Token 校验，可信来源校验及失效会话处理；权限、账号状态和密码变更及时影响已有会话。
- 欠费和预出院更新增加并发冲突提示，避免无提示覆盖。
- 权限管理交互与前后端验证完善，页面安全响应头和相关回归测试补齐。
- 修复测试环境 HTTPS 由 Nginx 转 HTTP 后，缺少可信来源配置导致登录报“请求来源不受信任”的部署问题。

### 配置与数据库

- 腾讯云环境必须设置 `APP_ALLOWED_ORIGINS=https://kangfu.pkucarewiki.cn`；修改后重启 `kangfu-test`。
- HTTPS 环境应配置 `SESSION_COOKIE_SECURE=true`；离线 HTTP 环境按实际协议配置。不得关闭来源校验或 CSRF 防护。
- 数据库基线为 Flyway V1～V23；本次版本流程补齐不新增迁移。升级已有测试环境不重建或清空数据。
- 环境文件、密钥、患者数据及构建缓存不提交 Git。
