# H5 页面适配补充修改计划

## 1. 修改目标

补齐 HIS 接口对接功能在 H5 页面上的功能入口、字段展示和移动端交互，使 H5 与 Web 端在业务能力、权限控制、运行状态和结果反馈方面保持一致。

本计划仅在本地开发环境实施和验证，不部署测试环境，不执行发布版本、Git 标签或生产部署操作。

## 2. 当前差异与问题

| 编号 | 页面 | Web 端现状 | H5 端现状 | 问题等级 |
| --- | --- | --- | --- | --- |
| H5-01 | 欠费明细 | 可手动同步在院欠费、出院欠费 | 顶部操作区被移动端样式隐藏 | 高 |
| H5-02 | 预计出院管理 | 可手动同步患者信息 | 顶部操作区被移动端样式隐藏 | 高 |
| H5-03 | 预计出院管理 | 列表和详情展示医保类型 | 移动卡片和移动详情均未展示 | 高 |

## 3. 修改范围

### 3.1 欠费明细 H5 手动同步

修改 `web/src/views/ArrearsDetailsView.vue`：

- 在移动端筛选工具栏或独立快捷操作区增加“同步在院欠费”和“同步出院欠费”按钮。
- 复用现有 `syncHis` 方法，不新增重复请求逻辑。
- 保持 `PERM_API_HIS_SYNC_TRIGGER` 权限控制。
- 任一同步运行时同时禁用两个同步按钮，避免重复触发。
- 保留加载状态和当前同步类型提示。
- 同步完成后刷新筛选项、统计和患者列表。
- 继续使用现有反馈区域展示批次号、总数、成功、失败、新增、覆盖和跳过数量。
- 同步失败时保留“查看导入记录”入口。

不直接取消现有 `.heading-actions` 的移动端隐藏规则，避免同时把文件导入、导出等原本不适合手机操作的功能全部暴露到 H5。

### 3.2 预计出院管理 H5 手动同步

修改 `web/src/views/DischargeManagementView.vue`：

- 在移动端工具栏或独立快捷操作区增加“同步患者信息”按钮。
- 复用现有 `syncPatients` 方法。
- 保持 `PERM_API_HIS_SYNC_TRIGGER` 权限控制。
- 同步过程中显示加载状态并阻止重复点击。
- 同步成功后刷新科室选项、统计和患者列表。
- 继续复用现有同步结果和错误反馈区域。

### 3.3 预计出院管理 H5 字段补齐

修改 `web/src/views/DischargeManagementView.vue`：

- 在 H5 患者卡片中增加“医保类型”。
- 在 H5 患者详情摘要中增加“医保类型”。
- 医保类型为空时统一显示“—”。
- 建议同时在移动详情摘要中展示患者性别，保持关键患者身份信息与 Web 端一致。
- 不将欠费模块“费别”与预计出院模块“医保类型”混用。

验收重点：患者信息同步后，H5 页面能够直接查看医保类型，且不影响预计出院时间及其他人工维护字段。

### 3.4 HIS 同步配置移动端适配

修改 `web/src/views/HisSyncConfigView.vue` 和必要的响应式样式：

- 保留桌面端表格。
- 增加 `mobile-only` 配置卡片列表。
- 每张卡片展示同步类型、启用状态、每日同步时间、运行状态、最近运行时间、最近成功时间、最近批次和错误摘要。
- 在卡片内提供保存按钮，并复用现有 `save` 方法及保存状态。
- 时间输入和开关控件保证至少 44px 的可触摸区域。
- 长错误信息自动换行，不造成页面横向溢出。
- 继续使用 `PERM_API_HIS_SYNC_CONFIG` 控制路由和菜单入口。

### 3.5 导入批次移动端适配

修改 `web/src/views/ImportBatchView.vue` 和必要的响应式样式：

- 保留桌面端表格并增加 `desktop-only` 标识。
- 增加 `mobile-only` 批次卡片列表。
- 卡片展示批次号、来源、交易码或文件名、手动/自动触发方式、状态、处理数量、开始时间及错误摘要。
- 失败批次提供“错误详情”按钮。
- 错误详情在 H5 使用全屏或近全屏弹窗。
- 逐条错误使用移动卡片展示，避免宽表格横向滚动。
- API 来源显示中文“接口同步”，Excel 来源显示“Excel 导入”，提高业务辨识度。

### 3.6 响应式样式

修改 `web/src/styles/main.css`：

- 新增 H5 同步快捷操作区样式。
- 按钮在窄屏下采用一列或两列网格布局。
- 为同步配置卡片、批次卡片和错误卡片增加统一间距、状态区和文本换行规则。
- 避免修改全局 `.heading-actions` 行为造成其他页面回归。
- 验证 320px、375px、390px、414px 宽度下无横向溢出。
- 验证横屏、刘海屏安全区以及弱网提示同时出现时的布局。

## 4. 权限与业务规则

- H5 和 Web 使用相同权限码，不新增移动端专用权限。
- 无 `PERM_API_HIS_SYNC_TRIGGER` 权限的用户不得看到手动同步入口。
- 无 `PERM_API_HIS_SYNC_CONFIG` 权限的用户不得看到或访问同步配置。
- 前端按钮隐藏不能替代后端鉴权，继续由现有后端接口校验权限。
- 自动同步与手动同步仍由后端统一互斥，H5 不实现独立锁逻辑。
- 错误信息继续使用脱敏摘要，不展示完整患者姓名、住院号和费用明细。
- 不修改患者信息同步的字段覆盖规则，不覆盖预计出院时间和院后管理字段。

## 6. 验收标准

1. H5 欠费明细页面可以按权限手动同步在院欠费和出院欠费。
2. H5 预计出院管理页面可以按权限手动同步患者信息。
3. 三类同步均有运行中状态，不能重复点击。
4. 同步结果在 H5 完整展示批次号和各项处理数量。
5. H5 患者卡片和移动详情能够查看医保类型。
6. HIS 同步配置可以在手机上完成查看、启停、修改时间和保存。
7. API 同步批次可以在手机上查看来源、交易码、触发方式、处理结果和错误详情。
8. 320px 及以上常用手机宽度无页面级横向滚动和控件遮挡。
9. 新增测试全部通过，前端类型检查和生产构建通过。
10. Web 桌面端原有功能和布局无回归。
